# Restaurante Gourmet - Frontend React

Este es el proyecto frontend desarrollado en React (con Vite) para la gestión del menú de un restaurante, conectado a una API REST backend.

## Tecnologías Utilizadas

- **React** (Vite)
- **CSS / Bootstrap / Tailwind** (Estilos UI)
- **Fetch API** (Consumo de datos)
- **Node.js & Express** (API Backend conectada)
